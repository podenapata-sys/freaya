# Freya Makeover & Salon — Website Preview

Single-page, mobile-first website preview for Freya Makeover & Salon (Shagufta New Road, opposite the Mirpur DOHS gate, Dhaka).

- English / Bangla toggle (add `?lang=bn` to the URL to open in Bangla)
- Draggable before/after slider for Hair Botox, hair colour and hair spa
- Appointment booking (services, date, time) that sends to WhatsApp
- Starfield hero with fanned photo cards, services, reviews, live "Open now" badge, map

Built by FutureStack Solutions. Photos are demo placeholders, to be replaced with the salon's own photos.
